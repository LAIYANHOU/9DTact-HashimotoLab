## 製作前の準備

1. 再利用する **CSI–USB 基板、LED 基板、白色シェル** と、ケーブル・ねじを確認します。基板の表記、配線、組み付け方向を撮影します。
2. [3つの STL](../hardware/README.md) を取得し、mm 単位のスケールとカメラ基板の仮組みを確認します。編集用の交換形式が必要なら SolidWorks から STEP を出力します。
3. 実際に使用したモールドの造形データを取得します。再設計する場合はシェル、シリコーン厚さ、シール面を確認します。元の平面 DXF は、そのまま造形できる立体モールドではありません。
4. [窓の外注ガイド](WINDOW_OUTSOURCING.md) に従って図面を準備します。本リポジトリには確定した見積書や発注記録は含まれていません。
5. [部品表](../bom/BOM_JP.md) と [材料ガイド](MATERIALS.ja.md) を確認します。第3層は指定リンクを使用し、第2層を別材料に置き換える場合は少量試験から始めます。

## 組み立てと確認の順序

以下は確認の順序であり、時間まで確定した注型レシピではありません。配合、脱泡、硬化、造形条件は実績を記録し、不明な値を推測で埋めないでください。

1. **機構を仮組みする。** 基板、ベース、レンズ、LED、遮光リング、白色シェルに無理な力がかからないか確認します。ねじ頭、ねじ込み長さ、底付きに注意します。
2. **カメラと照明を確認する。** 既存の CSI–USB 基板と LED を使い、撮影モード、露光、ゲイン、焦点を記録します。配線を挟まないようにします。
3. **アクリル窓を取り付ける。** シェルとの適合と光学面を確認し、接着剤による曇り、接着、後続のシリコーン硬化への影響を少量試験します。
4. **第1層の透明シリコーンを注型する。** 透明な光学媒体としての役割を保ちます。第2層用の軟質材料をそのまま代用しないでください。
5. **第2層を注型・脱型する。** Taobao の Shore 0 を使います。モールドの密封、表面、硬化適合性を確認します。**指で端を押したり引いたりせず、カッターナイフでモールドとシリコーンの界面を慎重に分離します。** [比較図と手順](DEMOLDING.md) を参照してください。
6. **第3層の黒色表皮を形成・脱型する。** 指定の [シリコーン](https://amzn.asia/d/08yFspH2) と [顔料](https://ja.aliexpress.com/item/1005012698616201.html) を使い、添加量と硬化条件を記録します。必要な表面と側面を遮光します。**この層もナイフで界面を分離し、感圧面や黒色表皮を切らないようにします。** 接着状態と押圧後の回復を確認します。
7. **LEAP Hand に取り付ける。** 固定、関節可動域、干渉、ケーブルの余裕、引張対策を確認してから制御運動を試します。改変後のねじ寸法は実物で確認が必要です。
8. **基準画像を再取得し、再校正する。** [元プロジェクトの校正手順](https://github.com/linchangyi1/9DTact#3d-shape-reconstruction) を使います。材料や機構の変更後は性能を再評価し、元の力推定モデルの精度が保たれるとは仮定しないでください。

## 引き継ぎ時に残す記録

| 確認項目 | 保存する資料 |
| --- | --- |
| 基板に負荷をかけずカメラを固定できる | 仮組み写真、実測クリアランス |
| 非接触画像が安定している | 生の基準画像、露光・ゲイン設定 |
| 中央と周辺の接触を識別できる | 同じ物体を各位置に押した画像 |
| 外光変化の影響を把握できる | 照明条件を記録した比較画像 |
| 繰り返し押圧後に回復し、表皮が剥離しない | 回数、回復時間、写真、研究室で定めた合格基準 |
| LEAP の動作で干渉や配線の引張りがない | 固定方法、動作動画 |
| 校正を再現できる | 元画像、校正ファイル、ソフトウェアの版 |

[製作記録テンプレート](BUILD_RECORD_TEMPLATE.md) を使い、空欄を「合格」と扱わないでください。

[部品表の写真欄](../bom/BOM_JP.md) で実物を識別できます。第1層は恵州ラベルとQRコードの白い2本、第2層は「SHORE A 0」の2本、第3層は黄色・青色の2容器です。JP-24 は再利用する LED 基板の写真です。

優先して追加するもの：モールドの造形データ、STEP、窓の図面、読み取れる材料型番と配合情報、顔料添加量、造形条件、カメラ仕様、再利用基板の配線、LEAP 固定方法。[未完了項目](KNOWN_GAPS.md) に一覧があります。

6つの CAD/STL は提供されたファイルと同じ内容で保存しています。親フォルダの元ファイルと `9DTact_BOM.docx` は変更していません。
