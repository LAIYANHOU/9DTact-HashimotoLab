# 9DTact 實驗室製作交接

日期：2026-11-18。此份記錄的「已確認」指製作者在交接中確認，不代表此次已重新組裝或做過性能測試。

## 先理解這一版

這是以原始 [9DTact](https://github.com/linchangyi1/9DTact) 為基礎、配合日本製作與 LEAP Hand 安裝的硬體版本。感測軟體、相機校正與重建流程仍參考原專案；本 repo 記錄修改零件、採購與製程差異。

| --- | --- | --- |

## 製作前準備

1. 清點現有 LED 板、白色外殼及其螺絲，先拍照記錄組裝與接線。這兩項目前是重製此版本的既有零件依賴。
2. 讀 [hardware/README.md](../hardware/README.md)，下載新增底座 STL、核對比例；需要交換 CAD 時再匯出 STEP，並量測現有相機及 PCB 後乾裝。
3. 取得模具的列印檔。若必須重新建模，先參考上游模具幾何，核對現有外殼與接觸層厚度；上游平面 DXF 不能直接送進切片軟體當成立體模具。
4. 依 [window 發包說明](WINDOW_OUTSOURCING.zh-TW.md) 確認圖面後詢價。此處提供的是準備流程，尚未向廠商送件或下單。
5. 依 [日本 BOM](../bom/BOM_JP.md) 逐項選型。實驗室沒有日本購入第二層矽膠的既有驗證結果；先按 [材料替換紀錄](MATERIALS.zh-TW.md) 做小樣。

## 建議的組裝與檢查順序

以下是供接手者使用的檢查順序，**不是已驗證的逐分鐘製程配方**。實際混合比例、脫泡、硬化及列印參數應填入製作紀錄；未知值不要猜。

1. **先乾裝機構。** 檢查相機 PCB、底座、鏡頭、LED 板、隔光環和白色外殼能否在不受力的情況下定位。確認緊固件的頭型、長度與埋入深度，不可讓螺絲頂到 PCB 或鏡頭。
2. **相機與 LED 單獨確認。** 記錄相機型號、USB 接法、解析度、曝光與對焦；LED 使用既有配置，先確認線材不會被夾住。
3. **安裝透明 window。** 使用核對過的壓克力件，清潔光學面；接著劑先做小樣，避免霧化、滲入有效視野或影響後續矽膠硬化。
4. **第一層透明矽膠。** 維持透明介質功能；不要把第二層 Shore 0 材料誤用在第一層。材料替換需先比對透光性與界面狀態。
5. **第二層半透明矽膠。** 本版採淘寶 Shore 0 號。使用 3D 列印模具前，確認密封、接觸面、脫模與固化相容性；用同材質／同表面處理做小樣後再製作正式件。
6. **第三層黑色表皮。** 遮光應包括接觸面與側邊；記錄黑色顏料與矽膠配比。確認按壓、放開後表皮不剝離，也沒有明顯環境光滲入。
7. **固定到 LEAP Hand。** 先以低風險的手動活動確認關節行程、干涉、固定件剛性、線材餘量及拉力釋放，再做受控運動。固定螺絲規格尚未完成實物核對。
8. **重取參考影像並校正。** 依 [原 repo 的校正流程](https://github.com/linchangyi1/9DTact#3d-shape-reconstruction)。此版本換過矽膠與機構，不可假設原版校正或預訓練力估計模型仍保有原精度；力估計需另外驗證，必要時重新蒐集資料。

## 接手驗收

| 檢查 | 應留下的證據 |
| --- | --- |
| 相機固定、PCB 無擠壓 | 乾裝照片與量測尺寸 |
| 無接觸時影像穩定 | 固定曝光／增益設定、原始參考影像 |
| 中央與邊緣皆可辨識接觸 | 同一測試物在不同位置的影像 |
| 環境光變化未造成明顯異常 | 同一曝光下照明變動測試 |
| 按壓後可恢復、表皮不剝離 | 重複次數、恢復時間及照片，門檻由實驗室訂定 |
| LEAP 活動時無干涉、線材不拉扯 | 固定方式及行程測試影片 |
| 校正可重現 | 原始影像、校正檔與軟體版本 |

使用 [製作紀錄模板](BUILD_RECORD_TEMPLATE.md) 留下結果。不要把本表未填的項目當成已通過驗收。

## 哪些地方最需要補

優先補齊：模具列印檔、底座的 STEP、window 最終圖面、Shore 0 實際包裝／配方、相機選購變體、LEAP 固定方式及各列印參數。完整清單見 [KNOWN_GAPS.md](KNOWN_GAPS.md)。
