# 相機壓克力 window：はざいや發包

製作者指定 [はざいや / Hazaiya](https://www.hazaiya.co.jp/) 作為透明壓克力 window 的可詢價廠商。這是發包窗口建議，沒有本次訂單、報價或驗收紀錄。

其餘 casting mold 使用 3D 列印；**不要把原版的壓克力模具板一起下單**。

## 發包前應有的圖面

| 欄位 | 現況 |
| --- | --- |
| 材質 | 透明壓克力／PMMA；牌號與成形方式待選定 |
| 板厚 | 原 9DTact 論文以 2 mm 為參考；本版最終值須量測確認 |
| 外形、角部與安裝面 | 須由現有白色外殼配合面確認；不能用外殼內部尺寸直接猜 |
| 尺寸、公差、切縫補償 | 尚未指定，需依配合與廠商加工能力確認 |
| 光學表面與有效區 | 要求保護光學面、無明顯刮傷／霧化；驗收標準待實驗室確認 |
| 數量 | 每顆感測器一片，加上實驗室自行決定的備品 |
| 最終檔案 | **待補** window 專用 DXF／SVG／AI；附帶尺寸標註圖供人工核對 |

[原版 fabrication](https://github.com/linchangyi1/9DTact/tree/main/9DTact_Design/fabrication) 內的 `mold_*.DXF` 是模具相關幾何，不應直接當作 window 的生產圖。先核對其他上游 CAD／現有 window，再匯出最終圖面。

## 詢價方式

Hazaiya 的 [圖面 WEB 詢價頁](https://www.hazaiya.co.jp/index.php/estimate-drawing) 列出 DXF、AI、SVG 上傳；[WEB 加工說明](https://www.hazaiya.co.jp/estimate) 區分加工方式。選用何種切割或精密加工，應由尺寸與廠商能力決定，不預先保證雷射加工的公差。

準備詢價時可使用以下日文備註（所有括號欄位須填完再送出）：

> 視覚式触覚センサのカメラ窓として使用する、透明アクリル部品の見積りをお願いします。添付図面の寸法単位は mm です。板厚［確定値］、数量［数量］、重要寸法・公差［図面参照］です。カメラの光路に入るため、両面の傷・白濁を避けたいです。希望公差に適した加工方法、材料、納期、価格をご提案ください。保護フィルムの有無もご教示ください。

此 repo 未對外送出詢價。收到產品後先乾裝、檢查光學面與鏡頭視野，成功後把最終圖面、報價規格及量測值留在製作紀錄中；公開時移除帳號、地址與訂單個資。
